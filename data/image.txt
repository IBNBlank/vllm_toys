请识别图片中的主要物体，并给出每个物体在 16 列 × 9 行网格中覆盖的 block range。使用中文描述，仅输出一个 JSON 对象，不要使用 Markdown 代码块。

网格与 block range 规则：
1. 图片左上角为原点，列从左到右编号 1～16，行从上到下编号 1～9。每个块的编号为 block_id=(row-1)*16+column，范围为 1～144。
2. block range 表示物体外接矩形覆盖的最小连续行范围和列范围，包含起止行、列，不能仅用物体中心点所在的单个块代替。
3. block_range.rows=[起始行,结束行]，block_range.columns=[起始列,结束列]。block_ids 列出上述矩形范围内的所有块编号，按从上到下、从左到右的顺序排列。编号的最小值和最大值之间不一定全属于这个矩形，不要直接展开成连续编号区间。
4. 按外接矩形与块有正面积交集来判定覆盖；边缘恰好落在网格线上时，不额外计入相邻块。若矩形为 [x1,y1,x2,y2]、图片宽高为 W、H，则起始列=floor(x1/W*16)+1，结束列=ceil(x2/W*16)，起始行=floor(y1/H*9)+1，结束行=ceil(y2/H*9)。行列分别限定在 1～9、1～16 内。
5. 同类但位置不同的物体分别列出。只描述可见内容，不确定或被遮挡的部分在 notes 中说明；无法识别物体时 objects 为空数组。

输出结构示例（数值仅用于说明格式，必须按实际图片确定）：
{
  "description": "整体场景、主要物体及空间关系的中文描述",
  "objects": [
    {
      "name": "物体的中文名称",
      "description": "该物体的可见特征",
      "block_range": {"rows": [2, 3], "columns": [4, 5]},
      "block_ids": [20, 21, 36, 37]
    }
  ],
  "notes": "定位误差、遮挡或其他不确定信息，没有则为空字符串"
}
